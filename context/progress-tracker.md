## Architecture Decisions

- shadcn/ui is configured with the `radix-nova` style (Radix primitives, `class-variance-authority`, Lucide icons, Tailwind v4 CSS variables). Generated `components/ui/*` files are treated as protected foundation components and must not be hand-edited.
- `lib/utils.ts` re-exports `cn` from the `cn` package (a compiled drop-in for `clsx` + `tailwind-merge`), rather than hand-rolling the helper.
- The Ghost design tokens documented in `ui-context.md` are now the canonical styling tokens. They live as CSS custom properties in `app/globals.css` and are mapped to Tailwind utilities via `@theme inline`. shadcn's own tokens remain only for the internals of generated `components/ui/*` primitives.
- Tailwind naming note: `--color-base` is only used for backgrounds (`bg-base`) because `text-base` collides with Tailwind's font-size utility. Text colors use the `copy-*` namespace (`text-copy-primary`, `text-copy-muted`, etc.).
- Editor chrome components live in `components/editor/` and contain composition only — no business logic.
- `/editor` (`app/editor/page.tsx`) is now a server component that fetches owned/shared projects and renders them through the client `EditorShell`; it is the home route, while `/editor/[projectId]` is the ownership-checked workspace route.
- The workspace route keeps the dynamic segment name `[projectId]` even though the spec calls the URL param `roomId` — the Liveblocks room ID intentionally stays aligned with the database project ID (spec 07 decision), and Next.js does not allow two different dynamic segment names at the same route level. The spec's `/editor/[roomId]` refers to this same URL shape.

- Workspace UI polish pass (visual refinement, no behavior change): added a `--color-on-brand: var(--bg-base)` token mapping (`text-on-brand`) in `app/globals.css` so filled-brand buttons can use dark text without raw color classes. `EditorNavbar` now stacks the project name over a `Workspace` subtitle, renders `Share` as a dark pill (`rounded-full bg-elevated border-surface-border`) and `AI` as a filled brand pill (`rounded-full bg-brand text-on-brand`) that toggles the AI panel (aria-pressed). `ProjectSidebar` became a floating inset panel (`bottom-2 left-2 top-16 rounded-2xl`), the My Projects / Shared switches now render as a segmented pill control (`rounded-full border-subtle-border bg-elevated` with `data-active:bg-surface` triggers), the active project row shows a cyan dot bullet (`bg-brand`) on `bg-accent-dim`, and the footer pairs a Clerk-derived avatar initial (via `useUser`) with a filled brand `New Project` pill. The workspace canvas is now a full inset `rounded-2xl` panel (`p-2` margin) with a token-based grid pattern and centered radial cyan glow (inline `backgroundImage` styles referencing `var(--border-default)` / `var(--accent-primary)` via `color-mix`), a compass icon tile, uppercase `WORKSPACE SHELL` eyebrow, and centered heading/description. The AI sidebar matches the same floating-panel treatment (`bottom-2 right-2 top-16 rounded-2xl w-96`) with an `AI Copilot` / `Placeholder panel` header, purple `Sparkles` chip, a `Chat surface pending` card (`Bot` icon on `bg-ai/15`), and a pinned `FUTURE HOOKS` footer card; the panel closes via the navbar toggle (no inline close button). Verified with `npx tsc --noEmit`, `npm run lint`, and `npm run build`.
